# 拟态风格 Todo 应用实施计划

## 目标描述
构建一个具有拟态设计风格（柔和阴影、微妙深度）的 Vue 3 Todo 应用。该应用将包含添加、完成和删除任务的功能。

## 用户审查要求
无。

## 建议变更

### 项目设置
- [新增] 安装 Tailwind CSS

### 设计系统
- [新增] `src/assets/css/neumorphism.css` (或扩展 tailwind 配置)
    - 定义高光/阴影颜色
    - 定义凸面/凹面形状的工具类

### 组件
#### [新增] src/Components/TodoInput.vue
- 带内阴影（凹面）的输入框
- 带外阴影（凸面）的添加按钮

#### [新增] src/Components/TodoItem.vue
- 带外阴影的列表项
- 完成状态的复选框/切换开关
- 删除按钮

#### [新增] src/Components/TodoList.vue
- 项目容器

#### [修改] src/App.vue
- 适合拟态风格背景色的主布局
- 标题

## 验证计划

### 自动化测试
- 运行 `npm run dev` 并验证无控制台错误。

### 手动验证
- 在浏览器中打开应用。
- 添加一个任务。
- 验证任务显示风格是否正确。
- 标记为完成（风格变化）。
- 删除任务。
- 验证拟态阴影（通常光源来自左上角）。
